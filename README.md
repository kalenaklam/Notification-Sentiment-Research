# Notification-Sentiment-Research: “Evaluating the Effect of Notification Sentiment on User Engagement on Mobile Devices”

This is source code I independently developed in Swift for a final project in CS464: Human Computer Interaction. The goal of this application was to analyze the relationship between notification sentiment and how fast a user would click on that given notification. This app aims to simulate and record this behavior over the span of a week. Reference the final project report for more details.
